Facet Environment & API Keys

API keys are securely held as environment variables for the current session. Keyless tools (Edge-TTS, FFmpeg, Wikimedia) work with zero configuration.

Session Key Override

To persist environment variables across terminal restarts or headless agent CLI runs, copy and run the shell commands below in your environment:

PowerShell (Windows) 
$env:OPENAI_API_KEY="your-openai-key"
$env:ELEVENLABS_API_KEY="your-elevenlabs-key"
$env:FAL_KEY="your-fal-key"
$env:PEXELS_API_KEY="your-pexels-key"
$env:PIXABAY_API_KEY="your-pixabay-key"
$env:ANTHROPIC_API_KEY="your-anthropic-key"
Bash / Zsh (macOS & Linux) 
export OPENAI_API_KEY="your-openai-key"
export ELEVENLABS_API_KEY="your-elevenlabs-key"
export FAL_KEY="your-fal-key"
export PEXELS_API_KEY="your-pexels-key"
export PIXABAY_API_KEY="your-pixabay-key"
export ANTHROPIC_API_KEY="your-anthropic-key"
Windows CMD (Persistent via setx) 
setx OPENAI_API_KEY "your-openai-key"
setx ELEVENLABS_API_KEY "your-elevenlabs-key"
setx FAL_KEY "your-fal-key"
