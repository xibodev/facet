How Facet Works: The 3-Tier Model

Facet is designed around a clean separation of concerns so human creators never have to memorize complex media commands or manually splice video clips.

1. You (The Director)

You prompt in plain English or open the Studio UI. You make creative choices and describe what you want.

2. AI Agent (The Producer)

Claude Code, OpenCode, or Copilot drafts scripts, plans scenes, and calls the Facet engine under the hood.

3. Facet Engine (The Render)

Stateless Go toolbox + Remotion React renderers compile code and neural audio into broadcast-quality .mp4.

The Two Ways to Use Facet

Workflow A: The Headless AI CLI

Run facet init my-video --engine claude. Your AI coding agent starts up, and you simply prompt:

> You: "Make a 30s explainer about how neural networks learn with animated bar charts."
> Agent: "Drafting script, synthesizing voiceover, compiling Remotion charts, rendering to renders/final.mp4..."

Workflow B: The Web Studio (`facet ui`)

Run facet ui in your project folder. Open http://localhost:8787 in your browser:

  • Track stage progress: Brief → Script → Audio → Scene Plan → Compose → Review → Deliver
  • Inspect audio waveforms, volume meters, and voice ducking curves.
  • Scrub video frames and examine extracted QA stills.

Installation & System Doctor

# Install with Go
go install github.com/xibodev/facet/cmd/facet@latest
# Install with PowerShell (Windows)
irm https://raw.githubusercontent.com/xibodev/facet/main/install.ps1 | iex
# Install with Bash (macOS & Linux)
curl -fsSL https://raw.githubusercontent.com/xibodev/facet/main/install.sh | bash

Workspace Structure & Artifacts

Running facet init <project-slug> sets up a clean, version-controlled workspace: 

my-project/
├── artifacts/
│   ├── brief.md              # Project concept and metadata
│   ├── script.json           # Timed narrative sections written by the AI agent
│   ├── scene_plan.json       # Visual shot breakdown and cinematography intents
│   └── explainer_props.json  # Remotion scene cut parameters and theme settings
├── narration/
│   └── voice.mp3             # Synthesized neural voiceover audio from Edge TTS
├── assets/                   # User-provided raw footage, audio tracks, or brand logos
├── renders/
│   ├── final.mp4             # Broadcast-ready rendered H.264 video file
│   └── review_frames/        # Sampled QA stills extracted by output_review
├── .claude/skills/           # Junctions to active capability packs (e.g. explainer)
├── .facet/
│   └── ownership.json        # Ownership ledger preventing clobbering of user files
├── .facet.yaml               # Pinned resolution, FPS (30), and voice
├── facet.lock.json           # Lockfile recording active packs and engine version
└── CLAUDE.md                 # Lean, action-biased prompt contract (<50 lines)

Remotion Scene Component Library

The Explainer pack (@xibodev/facet-pack-explainer) provides declarative visual scene components:

hero_title

Cinematic title card with subtitle, spring physics, and animated light scrim.

text_card

Centered punchy typography with customizable font size, color, and background.

stat_card / stat_reveal

Large animated metric callout (e.g., "8.1B", "99.9%") with descriptive subtitle.

comparison

Two-column comparison card contrasting concepts (e.g., Classical Bit vs Quantum Qubit).

callout

Framed callout box with border accent (info, warning, tip, quote).

terminal_scene

Simulated developer terminal with syntax-highlighted typing and command execution.

bar_chart / line_chart / pie_chart

Animated charts with count-up values, legends, customizable series, and donut modes.

kpi_grid

Multi-column dashboard KPI matrix (2, 3, or 4 columns) with count-up animations.

output_review Quality Gates

Before finalizing, the agent calls output_review to evaluate five automated technical gates:

  • Container & Codec Gate: Validates H.264 video codec (libx264), YUV420p pixel format, AAC 48kHz audio, and faststart MP4 flags.
  • Loudness & Audio Curve Gate: Evaluates Integrated LUFS (-14 to -23 LUFS) and prevents clipping (peak < 0 dBFS).
  • Silence & Dead-Air Gate: Asserts that audio silence intervals do not exceed the editorial limit (default: 2.5s).
  • Freeze & Black Frame Gate: Detects rendering glitches, stuck frame sequences, or unintentional black screens.
  • Frame Inspection Samples: Extracts high-resolution JPEG stills for visual verification.
