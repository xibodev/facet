Quickstart & Installation

Facet is distributed as a single Go binary, as an npm development dependency, and via system package managers.

# Install via Go
go install github.com/xibodev/facet/cmd/facet@latest
# Install via PowerShell (Windows)
irm https://raw.githubusercontent.com/xibodev/facet/main/install.ps1 | iex
# Install via Bash (macOS & Linux)
curl -fsSL https://raw.githubusercontent.com/xibodev/facet/main/install.sh | bash

Workspace Anatomy

Running facet init <project-slug> --engine claude constructs an isolated production workspace: 

my-project/
├── artifacts/
│   ├── brief.md              # High-level creative goals & audience metadata
│   ├── script.json           # Timecoded narrative sections and speaker directions
│   ├── scene_plan.json       # Visual shot breakdown and cinematography roles
│   └── explainer_props.json  # Remotion scene cut specifications and theme config
├── narration/
│   └── beat1.mp3             # Synthesized neural voiceover tracks from Edge TTS
├── assets/                   # User-provided raw footage, images, or music
├── renders/
│   ├── final.mp4             # Broadcast-ready rendered H.264 video file
│   └── review_frames/        # Sampled QA review stills extracted by output_review
├── .claude/skills/           # Directory junctions to active capability packs
├── .facet/
│   └── ownership.json        # Ownership registry preventing clobbering of user files
├── .facet.yaml               # Pinned resolution (1920x1080), FPS (30), and voice
├── facet.lock.json           # Pinned lockfile recording engine and active packs
└── CLAUDE.md                 # Action-biased prompt contract (<50 lines)

The Zero-Ceremony Turn 1 Directive

AI agents often fall into bureaucratic loops: listing file trees with ls, querying available tools with facet tools list, or reading empty scaffolded brief.md files.

Facet's prompt contract strictly prohibits discovery ceremony. The agent is required to draft artifacts/script.json and synthesize audio on Turn 1.

Standard Production Flow
  1. Turn 1: Write artifacts/script.json & call facet tools run edgetts --input artifacts/req_tts.json.
  2. Turn 2: Probe audio duration (media_probe) & write artifacts/explainer_props.json.
  3. Turn 3: Render composition via facet tools run video_compose --input artifacts/explainer_props.json.
  4. Turn 4: Run output_review and deliver renders/final.mp4.

Remotion Scene Components Reference

The Explainer pack (@xibodev/facet-pack-explainer) provides a rich library of declarative visual scene cuts:

hero_title

Cinematic title card with subtitle, spring physics, and animated light scrim.

text_card

Centered punchy typography with customizable font size, color, and background.

stat_card / stat_reveal

Large animated metric callout (e.g., "8.1B", "99.9%") with descriptive subtitle.

comparison

Two-column comparison card contrasting concepts (e.g., Classical Bit vs Quantum Qubit).

callout

Framed callout box with border accent (info, warning, tip, quote).

terminal_scene

Simulated developer terminal with syntax-highlighted typing and command execution.

bar_chart / line_chart / pie_chart

Animated charts with count-up values, legends, customizable series, and donut modes.

kpi_grid

Multi-column dashboard KPI matrix (2, 3, or 4 columns) with count-up animations.

output_review Quality Gates

Before concluding video production, output_review evaluates five automated quality gates:

  • Container & Codec Gate: Validates H.264 video codec (libx264), YUV420p pixel format, AAC 48kHz audio, and faststart MP4 flags.
  • Loudness & Audio Curve Gate: Evaluates Integrated LUFS (-14 to -23 LUFS) and prevents clipping (peak < 0 dBFS).
  • Silence & Dead-Air Gate: Asserts that audio silence intervals do not exceed the editorial limit (default: 2.5s).
  • Freeze & Black Frame Gate: Detects rendering glitches, stuck frame sequences, or unintentional black screens.
  • Frame Inspection Samples: Extracts high-resolution JPEG stills for visual and OCR verification.
