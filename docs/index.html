Get Started

Up and Running in 3 Steps

Install the binary, start a project, and let your AI agent handle the video production.

1

Install Facet

Single binary installation with Go, PowerShell, Bash, or Scoop.

go install github.com/xibodev/facet/cmd/facet@latest
2

Start a Video Project

Scaffolds workspace and launches Claude Code, OpenCode, or Copilot.

facet init my-video --engine claude
3

Prompt & Inspect

Describe the video to your agent, then preview output in the Studio UI.

facet ui # Opens http://localhost:8787
