From Concept to Rendered .MP4 in Minutes.

Facet pairs an autonomous AI creative producer with a stateless Go media engine, Remotion React compositions, and a live web studio. Zero manual editing tools, zero handoffs.

$ go install github.com/xibodev/facet/cmd/facet@latest
facet-workspace — claude turn-1 autonomous pipeline

# 1. Initialize workspace with explainer pack & Claude Code engine

$ facet init test-universe --engine claude

✔ Created workspace subdirectories: artifacts/, assets/, narration/, renders/

✔ Linked pack: explainer (Remotion React runtime ready)

✔ Scaffolded directive CLAUDE.md (<50 lines, action-biased)

# 2. Turn 1: Draft script & synthesize neural narration immediately

$ facet tools run edgetts --input artifacts/req_tts.json

✔ Synthesized narration/universe.mp3 (voice: en-US-ChristopherNeural, duration: 9.98s)

# 3. Turn 2 & 3: Lock cut timing & render Remotion composition

$ facet tools run video_compose --input artifacts/explainer_props.json

Rendering composition "Explainer" via Remotion React engine...

✔ Render complete: renders/final.mp4 (1920x1080 @ 30fps, 3 scenes, synced audio)

# 4. Turn 4: Automated multi-pass technical and visual QA review

$ facet tools run output_review --input '{"rendered_file": "renders/final.mp4"}'

✔ Output Review Passed: Video(h264/yuv420p), Audio(aac/stereo), Volume(-5.6dB peak), Freeze(0s)

Engineered for Full Autonomy

Facet rejects the traditional "script-only" and "manual-assembly" cop-outs. Everything needed to produce, code, and render video is self-contained.

Real Rendered .MP4 Deliverables

Never outputs half-finished scripts, web prototype mockups, or tells you to open Premiere Pro. Facet compiles broadcast-ready video files directly.

35 Stateless Go Tools

Compiled single binary execution for Edge-TTS, Google Flow (Veo 3.1 & Imagen 4), FFmpeg wrappers, silence cutting, audio ducking, frame sampling, scene detection, and loudness verification.

Remotion & React Runtimes

Express visual concepts as code: dynamic Bar/Line/Pie charts, stat reveals, comparison matrices, terminal screencasts, and animated typographic cards.

Zero-Key Neural Voiceover

Out-of-the-box neural voice generation with Microsoft Edge TTS. Zero API keys, zero credits, natural cadence, and instant multi-language support.

Automated Quality Review

`output_review` rigorously verifies duration matches, stream codecs (H.264/AAC), LUFS loudness, freeze frames, black frames, and extracts sampled QA stills.

Web Studio Interface (`facet ui`)

Inspect multi-project pipelines on port 8787: visual stage progression, interactive audio waveforms, frame scrubbers, and live JSON artifact inspector.

System Design

The Three-Tier Video Operating System

Clean separation of creative intelligence, stateless execution mechanics, and durable artifact files.

TIER 1 • INTELLIGENCE

AI Agentic Producer

Operates inside your AI coding CLI (Claude Code, OpenCode, Copilot). Acts as the creative orchestrator: understands requirements, drafts scripts, plans scenes, and reviews renders.

  • ✔ Zero-Ceremony Turn 1 execution
  • ✔ Reasoned editorial choices
  • ✔ Schema-backed JSON artifacts
Role: Story & Orchestration
TIER 2 • EXECUTION

Facet Go Engine

Stateless, deterministic CLI toolbox compiled in pure Go. Executes media operations, bridges to Remotion and FFmpeg, queries provider facts, and evaluates strict quality gates.

  • ✔ 35 compiled media tools
  • ✔ No database or daemon queues
  • ✔ Fast inline JSON / file arguments
Role: Deterministic Execution
TIER 3 • RUNTIMES & STUDIO

Composition & Studio

Remotion React, HyperFrames HTML/GSAP, and FFmpeg render layers turn JSON scene trees into pixels. The local Web Studio (`facet ui`) provides full timeline observability.

  • ✔ Remotion React composition engine
  • ✔ Local Web Studio on :8787
  • ✔ Durable project workspace files
Role: Rendering & Visual Verification
