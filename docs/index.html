Facet gives your AI coding agent production guidance and tools for editing, narration, animation, and rendering. Work in the terminal or use Studio to chat about a project and preview the media it produces.

Bring an installed, authenticated agent CLI. Media providers and rendering runtimes have their own requirements.

Example prompt, not a recorded production result

"Make a short explainer about how rain forms, with simple animated diagrams and narration."
Start with the idea. The agent can clarify the audience, use available tools, and write project files. Review the actual render before sharing it; a prompt is not a guarantee of a finished video.

Two Ways to Work

You describe the outcome. The agent plans and executes media work. Facet provides the project workspace, local tools, and access to configured providers.

In Your Terminal

Initialize a separate production directory and launch your chosen coding agent. Continue the conversation there to request changes.

facet init my-video --engine opencode

Supported engine names: claude, opencode, codex, and copilot. Install and authenticate that CLI separately.

In Facet Studio

Open the local browser interface to create or open a production, choose an available engine, send prompts, and inspect project artifacts.

facet ui

The default address is http://localhost:8787. Studio is a local interface, not a hosted service or a replacement for agent authentication.

From a New Production to a Preview

Studio connects a project folder to your agent conversation and the files it creates. No fabricated timeline or success screen is shown here.

  1. Create or open a production. Choose its name, folder, engine, and packs in the new-production form, then select Create & Launch.
  2. Choose an available engine and chat. Send a plain-language request. Missing engines need installation; a detected executable still needs a working login and model access.
  3. Inspect the output. Open available script, narration, and review artifacts. Play or download the rendered video when one exists.

Keep Revisions in the Same Project

"Make the opening shorter and lower the background music."

Reselecting the same project retains its active conversation. Changing project or engine starts separate context.

Reload is limited. The same browser tab can restore a completed conversation only while the current Studio process remains running. In-flight turns, earlier activity replay, and recovery after a Studio restart are not supported.

Project files remain on disk. After a restart, ask the agent to inspect those files rather than assuming it remembers the chat.

Production Packs

Packs contain instructions, pipeline definitions, and supporting content. They do not install every provider or make every described route executable. Select installed packs in Studio; basic CLI initialization selects Explainer.

Animated Explainer

@xibodev/facet-pack-explainer

Topic explainers, diagrams, text cards, comparisons, and charts using Remotion.

Requires the installed composer, its npm dependencies, and a supported browser. Narration needs a working speech route.

Cinematic & Documentary

@xibodev/facet-pack-cinematic

Montages of supplied, sourced, or generated images and footage, with grading and audio mixing.

Source media must be available and licensed for your use. Generated shots require a separately configured provider.

Screen Demo

@xibodev/facet-pack-screendemo

Software walkthroughs, supplied screen recordings, and synthetic terminal scenes.

Real product demonstrations need actual screenshots or recordings and access to the app. Synthetic scenes are not evidence of product behavior.

Talking Head & Avatar

@xibodev/facet-pack-talkinghead

Presenter scripts, edits to recorded takes, and provider-dependent avatar workflows.

Use supplied presenter footage or an available avatar/lip-sync provider with appropriate consent. Voice synthesis alone does not create a talking face.

Social & Short-Form

@xibodev/facet-pack-social

Vertical edits, podcast highlights, reframing, and captioned clips.

Needs source footage and accurate transcript/timing data for captions. Hook selection and framing still need editorial review.

Character Animation

@xibodev/facet-pack-animation

SVG character design, rigs, pose libraries, and authored action timelines.

Requires suitable character assets, rig and animation authoring, and a working renderer. The pack is not a bundled character-generation model.

Localization & Dubbing

@xibodev/facet-pack-localization

Translated voiceovers, subtitle timing, and localized exports of existing videos.

Needs source media, transcription/translation, and a supported target-language voice. Voice cloning and lip-sync need separate providers and consent; language review remains necessary.

Install the Source Bundle

Prerequisites: Git, Go 1.25+, Node.js 18+ with npm, and FFmpeg plus FFprobe on PATH. Linux/macOS also need Bash and tar. Rendering needs supported Chromium and its system libraries and fonts. Dependency downloads require network access.

Windows / PowerShell

git clone https://github.com/xibodev/facet.git
pwsh -File ./facet/install.ps1 -NonInteractive

The default installs binaries under %USERPROFILE%/.facet/bin and the bundle beside them. Reopen your terminal for the updated user PATH.

-NonInteractive still creates shortcuts. Use -NoShortcuts or -NoPath to opt out of those changes.

Linux / macOS

git clone https://github.com/xibodev/facet.git
bash ./facet/install.sh
export PATH="$HOME/.facet/bin:$PATH"

Installs binaries and the bundle under ~/.facet. The script does not edit shell profiles; add the PATH export there for future terminals.

Run the scripts from a complete checkout, not a pipe. go install builds the CLI alone, not the full production bundle. npm launchers do not guarantee delivery of native binaries. Read installation details and Windows flags.

facet doctor
facet ui

doctor reports dependencies and configuration; it does not render a video or certify that providers work. Install and authenticate your chosen agent before sending a prompt.

What to Know Before Producing

  • Generation is conditional. Provider credentials, browser sessions, quotas, and supported models can prevent a request from completing. Errors are not replaced with mock media; explicit mock mode is for testing, not delivery.
  • Google Flow needs separate setup. Install the standalone gflow CLI and its Chrome extension, grant site permissions for labs.google, and log in to Flow. Setup/status checks do not prove generation. Costs and credits depend on your account. See the prerequisite checklist.
  • Review is still your responsibility. Check the actual video, audio, captions, and asset rights. There is no fixed-turn, completion-time, or broadcast-quality guarantee.
  • Studio is local and sessions are limited. No in-flight reload recovery or restart persistence. Loopback binding also means ordinary Docker port publishing is insufficient.
