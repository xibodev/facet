Production Packs

Packs contain instructions, pipeline definitions, and supporting content. The Facet skill directs your agent to the relevant pack for the task. Optional tools and providers have their own requirements.

Animated Explainer

@xibodev/facet-pack-explainer

Topic explainers, diagrams, text cards, comparisons, and charts using Remotion.

Requires the installed composer, its npm dependencies, and a supported browser. Narration needs a working speech route.

Cinematic & Documentary

@xibodev/facet-pack-cinematic

Montages of supplied, sourced, or generated images and footage, with grading and audio mixing.

Source media must be available and licensed for your use. Generated shots require a separately configured provider.

Screen Demo

@xibodev/facet-pack-screendemo

Software walkthroughs, supplied screen recordings, and synthetic terminal scenes.

Real product demonstrations need actual screenshots or recordings and access to the app. Synthetic scenes are not evidence of product behavior.

Talking Head & Avatar

@xibodev/facet-pack-talkinghead

Presenter scripts, edits to recorded takes, and provider-dependent avatar workflows.

Use supplied presenter footage or an available avatar/lip-sync provider with appropriate consent. Voice synthesis alone does not create a talking face.

Social & Short-Form

@xibodev/facet-pack-social

Vertical edits, podcast highlights, reframing, and captioned clips.

Needs source footage and accurate transcript/timing data for captions. Hook selection and framing still need editorial review.

Character Animation

@xibodev/facet-pack-animation

SVG character design, rigs, pose libraries, and authored action timelines.

Requires suitable character assets, rig and animation authoring, and a working renderer. The pack is not a bundled character-generation model.

Localization & Dubbing

@xibodev/facet-pack-localization

Translated voiceovers, subtitle timing, and localized exports of existing videos.

Needs source media, transcription/translation, and a supported target-language voice. Voice cloning and lip-sync need separate providers and consent; language review remains necessary.

Recommended Installation

Use Facet with your agentic CLI. The interactive installer supports OpenCode, Codex, Claude Code, and GitHub Copilot CLI, and lets you choose the optional production tools you need.

Download and extract the installer package, then open a terminal in the extracted folder. Run pwsh -File ./install.ps1 on Windows (PowerShell 7) or bash ./install.sh on Linux/macOS.

Optional Dependencies

Local editing and rendering do not require media-provider API keys. Optional generation services may require separate credentials, account access, or credits. The installer explains optional downloads, and tools report missing configuration when you use them.

Select Remotion, Piper, gflow, or HyperFrames as needed. The dependency selection lists approximate download sizes and what each component adds.

Using Facet with Another Agent

Using a different agentic CLI? Ask your agent to inspect this repository and adapt Facet's skills and command-line tools to its own integration conventions. The installer currently supports the four CLIs listed above; other integrations are community-adapted and may need additional setup.

What to Know Before Producing

  • Generation is conditional. Provider credentials, browser sessions, quotas, and supported models can prevent a request from completing. Errors are not replaced with mock media; explicit mock mode is for testing, not delivery.
  • gflow is optional. It supports extension-free provider routes. Its help and errors explain the requirements of the provider you choose. Read about gflow.
  • Review is still your responsibility. Check the actual video, audio, captions, and asset rights. There is no fixed-turn, completion-time, or broadcast-quality guarantee.
  • Standalone is experimental. For now, we recommend using Facet through a supported agentic CLI.
For Integrators: Technical Reference

Use facet tools list and facet tools describe <name> to inspect your installed build. Registry entries and schema files are not proof of provider availability or an exhaustive compatibility contract.
