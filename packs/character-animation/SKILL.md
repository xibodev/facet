# 2D Character Animation Pack

Use this skill when producing animated character scenes, SVG vector animations, or illustrated explainer sequences.

## Overview

1. **Character Design & Rigs:** Define character parts, pivots, and layers in vector SVG format.
2. **Pose Library:** Build expression states (neutral, happy, serious) and key action poses.
3. **Action Timeline:** Choreograph movements (walks, gestures, transitions) to speech rhythm.
4. **Scene Assembly:** Render composite layers into animation clips.
5. **Sound Design:** Add foley effects and audio accents matching motion hits.
6. **Delivery QA:** Check frame rate smoothness and layer order integrity.
