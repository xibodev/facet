# Facet Brand Kit

This directory contains the canonical Facet identity assets for **Precision
Dovetail Assembly (Puzzle B)**.

## Contents

```text
brand/
  BRAND.md            usage and construction guidance
  LICENSES.md         licensing inventory
  provenance.json     human-readable source and derivation record
  tokens.json         portable brand tokens
  tokens.css          CSS custom properties
  preview.html        local visual inventory
  logos/              mark, wordmark, lockups, and monochrome variants
  icons/              favicon and application-icon variants
  og/                  canonical social SVG and generated PNG derivative
```

Open `preview.html` in a browser to inspect the supplied assets on their
intended light and dark neutral surfaces. The preview is static and has no
build step.

## Product Name

Use **Facet** in ordinary text and accessible names. Use **facet.** only as the
visual wordmark, with the terminal period in `#D92D48`.

## Site Integration

GitHub Pages serves files from `docs/`. The favicon, header mark, and default
social images there are projections of brand assets in this directory. See
`BRAND.md` for the source-to-projection map and accessibility guidance.

The kit does not change product claims, application behavior, or the existing
documentation layout.

## Regenerate the Social PNG

`og/og-default.svg` is the source of truth. The PNG is a deterministic
1200x630 render for a fixed environment: the repository locks Playwright and
Chromium, and the generator fixes CSS scale, viewport, and color profile. The
SVG intentionally keeps text live, so use the same available font stack when
comparing regenerated bytes across machines. From the repository root, run:

```text
npm ci
npx --no-install playwright install chromium
node scripts/generate-brand-og.mjs
node --test scripts/brand-assets.test.mjs
```

The generator writes `brand/og/og-default.png` and copies those exact bytes to
`docs/og-default.png`. Use `node scripts/generate-brand-og.mjs --check` to
verify both committed PNGs against a fresh render without changing either file.
Do not edit the PNG files directly.
